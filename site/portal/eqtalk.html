House rules — read before you play
This is not a contest. No points, no winner, no losing team.
Everyone gets the same number of turns. A miss just passes the question along — it costs nothing.
Never rush a child. The fuse pops at zero just for fun — the game still waits for you. An answer after the boom is still a ⭕.
Finish every game the same way: “Great job, everyone!” — praise the whole class, name nobody.
