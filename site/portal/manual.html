📋 2. 상담 신청 관리

홈페이지 상담 신청서로 들어온 신청을 확인하고, 상담일시를 정해 확정하면 신청자에게 확정 문자가 자동 발송돼요. (원장 관리 페이지 맨 위)
  1. 새 신청 확인 — "미처리만" 체크 시 아직 처리 안 된 새 신청만 보임. 갯수(5/10/20)로 표시량 조절, "🔄 최신 불러오기"로 갱신.
  2. 상담일시 입력 — 그 행의 "상담일시" 칸에 날짜·시간 입력 (예: 2026.08.25 15:00).
  3. 상태 선택 → 저장 — 상태를 확정으로 두고 "저장". 확인창이 뜨고, 확정하면 신청자에게 확정 문자 자동 발송. 취소·대기도 선택 가능.
  4. 발송 확인 — "발송기록" 칸에 "확정문자 발송 …" 뜨면 완료.
전체 원본은 "시트 열기 ↗"로 구글시트에서 볼 수 있어요(전화번호 포함 → 외부 공유 금지). 시스템 도입 전 옛 신청은 "미처리"에 안 뜹니다.

🔁 3. 보강 관리

결석 → 사유 판정 → 보강 일정 → 전날 자동 안내 → 완료. 재보강은 없고, 일정은 언제든 수정 가능하며 수정 이력이 남아요.

보강 가능 기준

사유보강
개인사정 (개인일정)불가
학교일정가능
병결 (약봉투·진료확인서 제출)가능 · 증빙
초상가능
  1. 결석 등록 — 학생 이름·반·학부모 연락처·결석일·사유·(병결이면)증빙 입력 후 "등록". 개인사정은 자동으로 보강 불가.
  2. 보강 일정 확정 — "보강 일시"에 날짜·시간 넣고 "일정 확정". → 전날 오후 5시에 안내 자동 발송 예약됨.
  3. 일정 변경 — 언제든 날짜 바꾸고 다시 "일정 확정". 수정 기록이 비고 칸에 자동으로 남아요.
  4. 보강 완료 — 보강 끝나면 "완료" 클릭. (필터: 진행중·완료·보강불가·전체)
전날 오후 5시 자동 안내: "내일 오후 O시 OOO 학생 보강이 있습니다…" 가 학부모께 발송돼요. 비고 칸에 자유 메모도 가능.

👩‍🏫 4. 강사 명단 관리

강사는 자주 바뀌므로 이름만 관리해요. 로그인은 학원 공용 계정을 함께 써요. (원장 관리 페이지)
  • 추가 — "강사 이름"(예: NEZ (Class 1)) 입력 후 "강사 추가".
  • 변경 — 목록의 이름을 바로 고치면 저장돼요.
  • 삭제 — 🗑 로 명단에서 제거.
여기 등록한 강사 이름은 선생님 페이지의 반 선택과 학생 반 배정에 쓰여요.

🧑‍🎓 5. 학생 명단 관리

학생 등록·수정·탈회·반 이동·교재 변경을 여기서 해요. (원장 관리 페이지)
  • 학생 추가 — 반(선생님)·세부반·이름·English·코드·(교재) 입력 후 "추가".
  • 수정 — 이름·교재·코드를 그 자리에서 고치면 자동 저장.
  • 탈회 ↔ 재원 — 버튼으로 토글. 탈회해도 기록은 남고 화면에서만 숨겨져요.
  • 반 이동 — "세부반" 칸을 다른 반으로 바꾸면 이동.
  • 삭제 — 🗑 (완전 삭제, 복구 불가). 탈회만 하려면 "재원/탈회" 버튼 사용.
  • 필터: 반·세부반·재원만 보기.
여기 명단이 원본 → 선생님 페이지에 그대로 반영돼요.

🏫 6. 선생님 페이지

강사가 반 전체 기록을 한 화면에서 입력. 공개한 항목만 학생·학부모 페이지에 반영돼요.
  • 성적·출결·태도·숙제 — 구글시트처럼 반 전체를 한 화면에서 체크·입력. 점수는 맞은/총 문항.
  • 📋 오늘 반 전체 메모 — 반 모두에게 보이는 공지(발행/수정/재발행).
  • 🗒️ 강사 일지 — 나만 보는 비공개 기록(저장). 날짜 바꾸면 지난 일지 확인.
  • 개별 메모 — 학생별 🔒 비공개 메모. 민감=공개 불가, 반복지도 3회+=학부모 공개(월말 반영).
  • 도구 — Writing Lab(PIN 없이 바로), IB PPT&TG, 자료실(노션) 연결.

📨 7. 문자 · 알림톡 자동발송

상담 확정·보강 안내는 자동 발송돼요. 카카오 알림톡이 승인되면 문자 대신 카톡으로 나가고, 실패 시 문자로 자동 대체돼요.
  • 상담 확정 문자 — 상태를 "확정"하면 즉시 발송.
  • 보강 리마인더 — 매일 오후 5시, 내일 보강 있는 학생에게 자동 발송.
  • 알림톡 전환 — 카카오 "보강_안내" 템플릿 승인되면 자동으로 알림톡(문자보다 저렴·열람률↑). 승인 전에는 문자로 발송.
비용(대략): 문자(단문) ~10원 / 문자(장문 LMS) ~33원 / 카카오 알림톡 ~8원. 긴 안내는 알림톡이 훨씬 저렴.

🔐 8. 계정 · 보안

  • 계정은 사람마다 따로 — 원장·실장 각각 계정. 공유하면 누가 무엇을 했는지 추적 불가.
  • 비밀번호 재설정: Supabase 대시보드 → Authentication → Users (원장만).
주의 (특히 실장과 공유 시): ① "확정"·"보강 안내"는 실제 학부모에게 문자가 나감(되돌리기 어려움) ② 학생 🗑 삭제는 복구 불가 ③ 상담·명단엔 전화번호 등 개인정보 → 외부 유출 금지.

🛠 9. 문제 생기면

  • 문자가 안 나감 — ① Solapi 잔액 확인 ② 발신번호 상태 ③ API 키/시크릿(카카오 연동·재발급 시 바뀔 수 있음). 상담 문자 자동화(Google Apps Script) 실행 로그에 원인이 한 줄로 떠요.
  • 페이지가 안 뜸/에러 — 정확한 주소(위 표)로 접속했는지, 로그인했는지 확인.
  • 그 외 시스템 변경·추가는 개발 담당에게 문의.
