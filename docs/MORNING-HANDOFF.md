# 아침 체크리스트 (밤사이 작업 마무리)

## ✅ 완료 (프로덕션 라이브 — https://www.amyschool.kr )
- **역할 로그인**: 홈 → 로그인 → 학생/학부모/선생님·원장. 직원(staff-login)은 아이디로 자동 분기
  - 원장 `klai.yj.pt@gmail.com` → 원장 페이지(admin)
  - 강사 `klai.yj.pt.1@gmail.com` → 선생님 페이지(teacher-hub). admin 주소 쳐도 선생님으로 튕김.
  - 로그인 폼 form화 → 브라우저 비밀번호 저장 인식.
- **원장 페이지**: 좌측 사이드바(대시보드·학생관리·직원관리·보강관리·교재관리·학습관리) + 우하단 홈/뒤로
  - 대시보드: 상담신청 · 주간알림(숙제미완2/결석지각1) · 오늘·확정보강(발송여부) · 구글시트 임베드 · 전체수업 그리드
  - 학생관리: 원생 명부(학부모전화) · 개별 시간표 편집(확정/수정안/학부모 비교표) · 학생추가 · 명단
- **실시간 개별 시간표**: 학생 불러오기 → 기존 확정표 → 수정안 저장(운영 안 바뀜) → 학부모 비교표(변경 노란강조) → ✅확정 시 운영 반영. 반명단·교실화면 자동 연동.
- **학생 이관 완료**: 162명 · 1238행 (이코딩 재원 103 전원 커버 + 개별그리드). 신규 5(김서우·서지율·이수호·홍서우·김동현) 포함, 탈회 2(박지현·윤지현) 제외.
- 과목 7: 정독(=원어민/엘리아/IB/pathways)·독해·단어&Extra·알파·문법·영어도서관·엘리아G/W. 시간 1~8시(+6시30분).

## ⚠️ 아침에 딱 하나 실행 (Supabase SQL 에디터)
`site/portal/sql/students-and-rls.sql` 전체 붙여넣고 Run:
- (1) **원생 명부(students, 학부모전화 103명)** 생성 → 원장 학생관리 "원생 명부"에 데이터 뜸
- (2) **전 테이블 RLS를 로그인전용(authenticated)으로 조임 → 타인(비로그인) 차단**
  - ⚠️ 현재는 anon 공개 상태(개발용). 이 SQL 실행해야 실제 보안 완성. 실행 후 각 페이지 로그인 상태로 정상 동작하는지 1회 확인.
