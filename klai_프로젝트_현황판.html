역할 5개 — 원장(전체+권한설정) · 부원장/관리자(대시보드별 권한 원장이 지정) · 선생님(담당 반) · 학부모(자녀+결제) · 학생(본인 학습만, 결제 비노출).

3 확정된 핵심 결정

  • 🔐 계정은 학원만 생성. 학생 아이디=영어이름+숫자. 학생+학부모 가정당 함께 생성.
  • 💳 결제·수강료는 이코딩이 담당 → 학부모 페이지에 이코딩 링크. 학생 화면엔 결제 요소 없음.
  • 🗓️ 출결은 선생님이 포털에서 직접 기록해 학생·학부모에 표시(이코딩 출결은 그대로 병행). 결제만 이코딩 링크.
  • 🗄️ 데이터베이스 = Supabase 확정. 구글시트는 월간레포트 보조 연동(단방향 1단계).
  • 📊 점수는 맞은/총(예: 18/20), 총 문항은 평가마다 다름.
  • 🔁 반이동: 기록은 학생에 귀속(이동해도 유지). 개별학습(알파·클라이)은 잦은 이동, 레벨반(원어민)은 고정.
  • ✍️ 선생님 입력 기본 비공개, 공개 스위치 켤 때만 학생·학부모에 게시.
  • 🎬 영상은 유튜브 비공개(Unlisted). 원어민 레슨플랜은 이미지 게시. 포트폴리오=알파리포트·원어민월말리포트·영상.
  • 🧩 스택: Next.js+TS+Tailwind+shadcn/ui, Vercel, PWA. 카카오 채널 연결.

! ⚠️ 놓치면 안 되는 것 · 원장님 확인/자료 필요

  • ✅ 출결·결제 방식 확정 — 출결=선생님 직접 기록, 결제=학부모 페이지에서 이코딩 결제 링크. (이코딩 엑셀 가져오기 불필요)
  • 🔗 이코딩 학부모 결제 URL — 학부모 결제 페이지/앱의 정확한 주소를 알려주시면 링크 버튼에 연결.
  • 🔗 업무자동화 기존 시스템(알파 결과리포트 · 원서반 월말리포트 · 교재주문서) 폴더 연결됨 → 파일이 iCloud '클라우드 전용'이라 파인더에서 '지금 다운로드' 후 포털에 이식 예정.
  • 📚 엘리아 나머지 교재 · 키스톤 6단계 목차 캡처 업로드 → 생성기 교재 추가.
  • 🏫 엘리아영어·클라이영어 공식 소개 정보(홈페이지/자료).
  • 📷 학원 실제 IB·수업 사진(저작권 안전한 자체 사진).
  • 📇 기존 학생 명단·성적(구글시트 등) → Supabase로 1회 이전.
  • 🌐 도메인 확정: amyschool.kr (가비아 구매) → 배포 시 Vercel 연결(A @→76.76.21.21, www→CNAME cname.vercel-dns.com). · PWA 아이콘 · 카카오 알림톡(선택).

4 반드시 통과할 필수 체크 (개발 시)

  • ① RLS 권한 테스트 — 학생 계정으로 남의 기록·결제가 안 보이는지 배포 전 실제 확인. (최우선)
  • ② 알파 파이널 → 레벨 자동 매칭 — 매칭키=영어이름+숫자, 자동 반영 후 관리자 확정.
  • ③ 입력 표준화 — 과제·점수 표기 통일(자동완성/형식 검증).
  • ④ 공개 기본값 비공개 — 임시 기록이 바로 노출되지 않도록.
